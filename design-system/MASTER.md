# 显示屏控制系统统一设计规范

本文件是网页控制台、Server Manager、Windows Agent 和 Android Agent 的统一视觉来源。
后续版本修改界面时，优先复用这里的语义颜色、字号和间距，不为单个页面
临时发明另一套风格。

## 产品定位

- 类型：企业内部实时运维控制台
- 关键词：可靠、清晰、克制、低学习成本
- 默认主题：浅色 · 运营蓝白控制台
- 界面语言：简体中文
- 核心原则：真实状态优先于装饰；每个界面只突出一个主要操作

## 颜色

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| 页面背景 | `#F5F8FD` | 网页、桌面窗口和 Android 配置面板背景 |
| 卡片背景 | `#FFFFFF` | 内容卡片、表格、表单 |
| 主文字 | `#0F172A` | 标题、关键数据 |
| 次文字 | `#64748B` | 说明、时间、辅助信息 |
| 边框 | `#DBE5F0` | 卡片、输入框、分隔线 |
| 主操作 | `#2563EB` | 保存、连接、亮屏等唯一主要按钮 |
| 主操作悬停 | `#1D4ED8` | 网页按钮悬停 |
| 成功/在线 | `#15803D` | 在线、健康、执行成功 |
| 警告 | `#A16207` | 待确认、未验证 |
| 危险 | `#DC2626` | 删除、卸载、错误 |

状态不能只靠颜色表达，必须同时显示“在线”“离线”“未验证”等文字。

## 字体与层级

- 字体：`Microsoft YaHei UI`, `Segoe UI`, sans-serif
- 页面主标题：28–32px / 700
- 卡片标题：16–18px / 600
- 正文与表单：14–16px / 400
- 辅助信息：12–14px / 400
- 设备数量、时间等数据使用等宽数字特性，避免刷新时跳动

## 间距与尺寸

- 采用 4px/8px 的倍数：`4, 8, 12, 16, 24, 32, 48`
- 网页内容最大宽度：1680px；桌面窗口内容边距：20–32px
- 输入框和按钮高度不低于 40px；重要操作不低于 44px
- 卡片圆角：16–22px；按钮和输入框圆角：10–12px
- 阴影只用于区分卡片层级，保持轻微，不使用霓虹、玻璃或渐变装饰

## 组件

- 主按钮：实心蓝底白字，一个页面最多一个同层级主按钮
- 次按钮：白底、浅灰边框、深色文字
- 危险按钮：白底红字红边框，与普通操作留出间距
- 状态徽标：浅色底 + 深色文字 + 状态圆点
- 表单：始终显示标签；错误紧邻字段；保存期间禁用重复提交
- 表格：表头浅灰、行高舒适、长文本可换行；小屏幕改为设备卡片
- 空状态：说明为什么没有数据，并给出下一步操作
- 日志：时间、设备、动作、结果分列，失败项同时显示原因和恢复建议

## 交互与无障碍

- 所有异步按钮在执行时显示“处理中…”并临时禁用
- 成功和失败都提供明确反馈；错误信息说明下一步怎么处理
- 删除设备、卸载服务等不可逆操作必须二次确认
- 网页保留可见的键盘焦点，图标按钮必须有可读名称
- 动效仅使用 150–250ms 的颜色或透明度变化，并尊重
  `prefers-reduced-motion`
- 网页需在 375、768、1024 和 1440px 宽度下无横向滚动

## 跨端一致性

- 四个界面统一使用“屏控中心 / 屏控助手”品牌名、上述颜色和同一状态用语
- 网页负责设备和批量控制；Server Manager 负责服务生命周期；
  Windows Agent 负责本机连接和屏幕动作，职责不能混在同一个界面
- 桌面端优先使用 Windows 原生控件，但通过颜色、间距、按钮层级和文案与网页保持一致
- Android Agent 状态在上、配置在下；权限说明必须转化成现场人员能执行的提示，不出现 Windows/C 盘文案
