# 登录安全预览设计说明

## 任务边界

本轮只制作登录页视觉与交互提示预览，不修改 Server、验证码生成器或生产网页。用户确认某个方向后，才把选中的视觉与会话行为落实到正式源码并补测试。

## 已知上下文

产品是公司内部使用的“屏控中心”，通过局域网页统一管理 Windows 与 Android 显示设备。界面已有明确的“运营蓝白控制台”方向：浅灰蓝页面、白色功能面板、企业蓝主操作、绿色成功状态、红色错误状态；气质应可靠、清晰、克制、低学习成本。登录页面向办公室管理人员，不是互联网营销页面，不应出现夸张装饰、复杂动效或陌生术语。

## 本轮要表达的两件事

1. 单一管理设备登录：管理员在新设备成功登录后，旧设备的会话立即失效。旧设备下一次请求或定时检查时，页面应清楚说明“此账号已在另一台设备登录，本设备已安全退出”，而不是笼统显示“登录状态已失效”。不使用 IP 绑定，因为同一局域网、移动网络和浏览器切换都可能导致误判；以后端保存的唯一会话标识为准。
2. 更易用的图形验证码：继续使用 5 位不易混淆的字母与数字，不区分大小写。每个字符加入轻微旋转、基线错位、缩放或切片偏移，配少量曲线与噪点。人眼应在约 1 秒内读出，避免强模糊、密集划线和字符互相覆盖。正式实现使用服务端生成的位图或轮廓路径，预览中的 SVG 只用于比较视觉强度。

## 共同内容与尺寸

- 输出：3 个独立 HTML 登录页预览与对应 PNG。
- 统一视口：1440 × 900。
- 共同字段：用户名、密码、5 位验证码、刷新验证码、登录按钮。
- 共同状态：正常登录态预览 + “被另一台设备顶下线”的明确提示。
- 输入框与主按钮高度不低于 44px；所有字段有可点击标签；错误或会话变化使用 `aria-live`；按钮有可见焦点。

## 三个方向

- A「轻量波浪」：延续现有左右分栏，验证码只做轻微旋转与基线波动；会话被替换时使用右上角安全提示卡。最接近现有页面，学习成本最低。
- B「安全门禁」：登录卡居中，左侧加入简洁的单设备登录规则；验证码采用小幅切片偏移；会话被替换时使用页内红色提示条。信息更明确，整体更紧凑。
- C「会话控制台」：登录与会话状态并排，让“当前仅允许一台管理设备在线”成为显性信息；验证码使用轻微透视与弧线干扰；被顶下线状态用独立会话卡表示。解释最充分，但信息密度也最高。

## Form 推导

- 叙事角色：进入控制台前的安全门禁。
- 观众距离：办公室笔记本约 60–90cm，兼顾触控一体机。
- 视觉温度：冷静、可信、不过度警告。
- 容量估算：首屏只容纳产品说明、3 个字段、1 个主操作与 1 个会话提示。
- 视觉母题：唯一“控制席位”——登录不是普通账户入口，而是接管唯一管理席位。
