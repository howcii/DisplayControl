Windows Agent 使用方法
=====================

最简单：
1. 双击“DisplayControl.Agent.exe”
2. 填服务器地址、设备编号、设备名称
3. 如果要放到 A 盘或其他位置，在 Agent 面板里点“选择安装位置”
4. 点“保存并连接”

配置保存在当前文件夹 config\appsettings.json，不复制到 LocalAppData。
Agent 面板里的“选择安装位置”只复制 Windows Agent 包到你选择的位置，不会强行安装到 C 盘。
设置开机启动时，Windows 只会在当前用户启动项里放一个快捷入口；程序文件仍在你选择的目录。

目录说明：
- 第一层的 DisplayControl.Agent.exe 是直接运行入口。
- config 目录保存配置文件 appsettings.json。
- tools 目录保存可选辅助脚本，普通用户不需要打开。
