展示屏 Android Agent V1.6.9 安装说明
=================================

文件：
- DisplayControlAndroidAgent-v1.6.9.apk
- DisplayControlAndroidAgent-v1.6.9.sha256.txt
- 启用安卓休眠权限-ADB.cmd
- tools\adb\adb.exe 及配套文件

安装：
1. 把 APK 复制到安卓展示屏/会议一体机。
2. 在安卓设备上允许“安装未知来源应用”，安装 APK。
3. 打开“屏控 Agent”，填写服务器地址，例如：
   http://192.168.1.100:8080
4. 填写设备编号和设备名称，点击“保存配置”。
5. 点击“测试连接服务器”，成功后点击“启动/重启 Agent 服务”。

权限：
- 黑幕功能不需要系统锁屏权限。
- 真正休眠需要点击“启用系统休眠权限”，在 Android 系统页面启用“屏控 Agent 休眠权限”。
- 如果点击“启用此设备管理应用”后返回程序仍显示未启用，说明大屏固件没有真正授予权限。
- 这时请在电脑上连接大屏 USB 调试，双击“启用安卓休眠权限-ADB.cmd”，让 ADB 尝试启用设备管理员和系统设置权限。
- 如果普通授权和 ADB active-admin 都失败，说明普通 APK 无法取得这台大屏的系统休眠权限，需要厂商电源接口、设备所有者模式或继续使用黑幕模式。
- 建议点击“电池后台设置”，允许忽略电池优化，减少后台服务被系统杀掉。

现场逻辑：
- Agent 空闲轮询约 1 秒，比旧 V1.5 的约 15 秒轮询更快。
- 同一个网页命令只执行一次；网络抖动时只补发回执，不会重复休眠。
- 现场人员手动唤醒设备后，Agent 不会再次执行旧休眠命令。
- 黑幕异常时，现场人员可以五连点黑屏区域退出。

安装位置说明：
- Android APK 的实际安装位置由 Android 系统决定，普通 APK 不能像 Windows 程序一样选择文件夹。
- 本项目保证 APK 文件本身放在项目发布包目录内；安装后的应用配置保存在 Android 应用私有目录。
