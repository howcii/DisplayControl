# Server V11 基线测试报告

测试日期：2026-07-23  
测试环境：Windows 10 x64、.NET SDK 10.0.302、Release 配置  
测试地址：仅本机 `127.0.0.1:18081`，未影响现有 Server V10

## 结果摘要

当前恢复基线通过编译、核心状态逻辑、HTTP 并发、鉴权边界和 SignalR
连接测试。它尚未恢复登录、SQLite、真实屏幕控制和 V15 实机协议，因此
不能作为生产版发布。

## 编译

- 解决方案 Release 编译成功
- 4 个项目全部生成
- 0 个警告，0 个错误

## 核心逻辑

1. 协议版本边界

3. 旧连接断开不覆盖新连接

## SignalR

- 20 台模拟 Agent 同时连接，发送 2,000 次心跳：全部成功
- 30 台模拟 Agent 持续约 11.3 秒，发送 3,000 次心跳：30/30 成功
- 所有连接均以 WebSocket 状态码 1000 正常关闭
- 测试结束时 V11 进程工作集约 79.94 MB，私有内存约 36.4 MB
- 未出现服务崩溃、连接泄漏提示或未处理异常

## 测试中发现并修复

原 Agent Hub 限流为每 IP 30 请求/分钟。SignalR 一次连接通常包含协商和
传输两个请求，导致同一 IP 实际约 15 台 Agent 后开始失败。

已修改为配置项 `RateLimits:AgentHubRequestsPerMinute`，默认 120。
修复后 20 台和 30 台 Agent 测试均通过。
