# 版本更新说明

文档日期：2026-08-03  
对外版本：2026.08.03.1 直接运行版  
兼容组合：Server 11.7.0 + Windows Agent 16.6 + Android Agent V1.6.9

## 项目版本说明

本版本是在旧成品基础上重新建立的可维护源码工程，用于继续迭代公司的展示屏
集中控制系统。它不是旧源码的反编译副本。内部服务名仍保留 `DisplayControlCenterV11`
以兼容 Windows 服务升级；对外发布包、网页和管理器使用日期/小版本号标识最新版，
避免继续只看 V11/V16 分不清新旧。

## 2026.07.29.3 Android Agent V1.6.4 大屏休眠增强版

- 修复休眠兼容链路中过早停止按键尝试的问题：`SLEEP` 已发送但系统仍亮屏时，会继续尝试 `SOFT_SLEEP` 和 `POWER`。

- 休眠回执会写明每个按键是否已发送、系统是否仍报告亮屏，方便判断是权限问题还是固件拦截。
- APK 内部版本号升级为 `versionCode=20` / `versionName=1.6.4`。

## 2026.07.29.2 Android Agent V1.6.3 休眠兼容增强版

- 针对 M1 Pro 86 / Android 8 定制会议屏“设备管理器已尝试启用但休眠仍不可用”的现场问题，增强 Android 休眠链路。
- 网页“休眠”命令现在按顺序尝试三种通道：Android 设备管理员 `lockNow()`、系统睡眠按键 `input keyevent`、系统设置超时休眠。
- 新增 `WRITE_SETTINGS` 权限和 Agent 面板“允许系统设置”按钮；如果设备管理员锁屏被固件拦截，可尝试把系统息屏超时临时改为 1 秒来实现休眠。
- 新增“本机休眠测试”和“恢复息屏时间”按钮，便于在显示屏本机直接验证，不必每次从网页下发。
- 亮屏/手动唤醒后会自动恢复原系统息屏时间，避免旧休眠设置反复压制现场人员操作。
- Agent 面板新增设备能力诊断：设备管理特性、安全锁屏特性、系统设置权限、后台稳定模式。
- 休眠仍坚持真实回读：只有 Android 系统报告屏幕非交互才标记 `verified`；如果三种通道都失败，网页会显示明确失败原因，不会偷偷退化成黑幕。
- APK 内部版本号升级为 `versionCode=19` / `versionName=1.6.3`。

## 2026.07.28.7 Android Agent V1.6 源码重建版

- 新增 `src/DisplayControl.AndroidAgent` 原生 Android Java 源码工程，不再只依赖旧 V1.5 成品 APK 或反编译补丁。
- Android Agent 空闲轮询改为约 1 秒；网页下发黑幕/亮屏/休眠后，移动端会更快领取命令并回执。
- 黑幕、休眠、亮屏三种行为拆开实现：黑幕只打开全屏黑色 Activity；休眠只在启用 Android 设备管理器锁屏权限后调用系统锁屏；亮屏会解除黑幕并请求系统点亮屏幕。
- 修复“休眠退化成黑幕”的现场问题：未授权系统锁屏权限时，V1.6 会明确回执失败，不再偷偷执行黑幕。
- 新增命令去重与回执重试：同一个 `commandId` 只执行一次；网络抖动或服务器重复下发时，只补发上次结果，不会重复休眠，现场人员手动唤醒优先。
- Android Agent 面板改为蓝白卡片 UI，包含服务器地址、设备编号、设备名称、轮询间隔、开机自启、连接测试、黑幕测试、解除黑幕/亮屏、系统休眠权限和电池后台设置。
- Android 真实状态上报改为由本机状态回读生成：黑幕 Activity 前台显示为 `blackout`，系统非交互状态显示为 `standby`，正常交互显示为 `on`。
- 发布脚本改为构建 V1.6 APK 并复制到 Android 发布包；旧 V1.5 兼容 APK 仍保留在 `third_party/android` 作为追溯材料，不再作为当前安装包。
- Android 构建工具链安装在 `A:\CodexTools`，Gradle 构建缓存与临时源码路径使用 `A:\CodexProjects\DisplayControl`，减少 C 盘占用并绕开中文路径导致的 Gradle `Bad pathname`。

## 2026.07.28.6 Android控制修复版

- 修复 Android Agent V1.5 连接成功但网页控制无效的问题：APK 实际读取命令对象中的
  `requestId` 和 `command` 字段，而上一版只返回 `commandId` / `commandName`。
  Server 现在同时返回新旧字段，旧 APK 可直接识别 `screen_on` / `screen_off`。
- 修复 Android result 回执无法归档的问题：旧 APK 回传 `requestId`，Server 现在把
  `requestId` 作为 `commandId` 的兼容别名解析，网页命令结果不再等待到超时。
- Android HTTP 轮询设备使用更长的命令保留窗口，避免 15 秒轮询、移动系统后台调度或
  临时网络波动导致 Server 过早判定“Agent 未在限定时间内返回确认”。
- 修复 Android 屏幕实时状态长期显示“未知”：旧 APK 首次尚未产生屏幕状态或上报
  `unknown` 时，Server 会按“已连接亮屏在线”兜底显示；已有状态不会再被空心跳覆盖成未知。
- 发布烟测新增旧 Android APK 协议字段回归：覆盖 `requestId + command` 取命令、
  `requestId` 回执，以及 Android 初始 unknown 状态兜底。
- Server 对外版本更新为 11.7.0；Windows Agent 仍为 16.5，Android APK 仍为 V1.5 兼容成品。
- 现场实测补充：原 Android V1.5 APK 的后台轮询约 15 秒，黑幕/亮屏会有明显延迟；
  已提供 `DisplayControlAndroidAgent-v1.5-fastpoll-1s-测试版.apk` 用于验证 1 秒快速轮询。
- 现场实测补充：原 Android V1.5 APK 的“休眠”实际是安全软件待机，即黑幕 Activity，
  没有调用 Android 系统锁屏/真正息屏接口；如果需要真正 Android 休眠，必须重建 Android Agent V1.6。

## 2026.07.28.5 Android兼容修复版

- 修复 Android Agent V1.5 无法连接新版 Server 的问题：从 APK 中确认旧版 Android
  使用 HTTP 轮询接口 `/api/android-agent/poll` 和 `/api/android-agent/result`，
  而不是 Windows Agent 使用的 SignalR `/hubs/agent`。
- Server 新增 Android V1.5 HTTP 兼容层：Android 轮询时会完成注册、心跳入库、

- Server 新增 Android 结果回执接口：Android 执行完成后回传 `commandId`、
  `screenStatus`、`screenStatusVerified` 等字段，网页命令结果会正常收束。
- Android 命令响应同时返回顶层 `commandName` 和 `command` 对象，兼容 APK 内部
  `optString` / `optJSONObject` 两种读取方式。
- 发布烟测新增 Android V1.5 模拟轮询：覆盖注册在线、网页下发 Android 命令、
  Android 轮询取命令、Android result 回执和网页命令结果 verified 收束。
- Server 对外版本更新为 11.6.0；Windows Agent 仍为 16.5，本次不需要更新 Windows Agent 代码。

## 2026.07.28.4 现场优先增强版

- 修复 Windows Agent 在“黑幕 → 亮屏”连续操作后容易变成“未响应”的问题：
  显示器电源消息不再阻塞 WinForms UI 线程，改为后台发送异步系统消息，并缩短兜底等待时间。
- 黑幕窗口关闭流程增加重入保护和逐窗口异常捕获，避免远程亮屏解除黑幕、现场键鼠解除黑幕同时发生时拖垮 Agent。
- Agent 增加 1 秒一次的本机人工接管检测：休眠后只要检测到现场键鼠唤醒，就立即把状态改回亮屏并上报，
  不再继续实施休眠/息屏逻辑。
- Agent 修正 Windows `GetLastInputInfo` 长开机时间下的 tick 计算，避免本机人工操作识别不稳定。
- 控制网页的“真实屏幕状态”不再显示“亮屏（未验证）/休眠（未验证）”这类状态胶囊；
  内部仍保留 `screenStatusVerified` 字段，但用户界面只显示“亮屏 / 休眠 / 黑幕 / 未知”。
- Server 在收到 Agent 命令回执后会立即同步设备状态更新，减少只等 30 秒心跳才刷新网页状态的情况。
- 命令明细文案改为“状态已按 Agent 回执即时刷新，现场人工操作优先”，不再反复显示“物理亮度需现场确认”。
- Windows Agent 对外显示版本更新为 16.5；Server 对外版本更新为 11.5.0。

## 2026.07.28.3 现场优先修复版

- 调整 Windows Agent 控制原则：网页远程命令只下发一次，不再持续压过现场人员的手动操作。
  现场键盘/鼠标操作会被识别为人工接管；如果此前处于休眠状态，Agent 会把状态改回“亮屏（未验证）”，
  不再继续维护“必须休眠”的旧状态。
- 黑幕遮罩支持现场紧急解除：黑幕窗口检测到鼠标或键盘操作后会立即关闭，并向 Server 上报

## 升级注意事项

1. 升级前完整备份当前 Server 包目录，尤其是 `data`。
2. 新版本先在非 8080 临时端口完成登录、网页、Agent 与命令测试。
3. 确认新版本可用后再停止旧服务，避免测试过程影响正在使用的 V10。
4. 将新包解压到项目目录内的独立版本文件夹，再通过管理器安装/更新服务。
   安装器会在新目录 `data` 为空时迁移上一 V11 服务目录的数据。
5. Windows Agent 必须核对 Server 地址、设备编号和设备名称，不能让多台设备共用编号。
6. 发布区只保留当前版本和 `_previous` 中一个前版本；删除旧快照前先验证当前包可回滚。
